# NYC-taxi-fare-prediction
A machine learning project to predict NYC taxi fares using regression models.

A machine learning project to predict New York City taxi fares using various regression techniques.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Attar9132/NYC-taxi-fare-prediction/blob/main/NYC_Taxi_Fare_Prediction.ipynb)

## 📊 Project Overview

This project uses a historical dataset of NYC taxi rides to predict fare amounts based on:

- Pickup and drop-off coordinates
- Distance traveled
- Time of day and day of the week
- Other engineered features

### 🔍 Objectives:
- Clean and preprocess real-world data
- Visualize trends and correlations
- Train and evaluate regression models (e.g., Linear Regression, Random Forest)
- Measure performance using RMSE and MAE

## 🧠 Models Used

- 📈 Linear Regression
- 🌲 Random Forest Regressor
- 🔧 Feature Engineering & Standardization

## 📁 Dataset

This project uses data from Kaggle:  
**[New York City Taxi Fare Prediction](https://www.kaggle.com/c/new-york-city-taxi-fare-prediction)**

> Dataset includes pickup/dropoff coordinates, datetime, and fare amount.
